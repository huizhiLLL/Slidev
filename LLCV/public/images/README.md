# 待补真实图片

按 LLCV/assets.ts 中的五个文件名放入此目录。缺图时组件显示明确占位，不展示虚构的魔方照片、识别标记或产品界面。

1. input-oblique.webp：实体魔方斜视照片，建议 4:5，完整保留魔方。
2. observed-15.webp：同一受控场景的标注照片，突出顶面 9 格及两个侧面顶行各 3 格，建议 5:4。
3. prototype-overview.webp：cuberoot.me 拍照查公式的真实全景截图，建议 16:10，宽度至少 1600 px。
4. prototype-grid.webp：角点与网格识别截图，建议 2:1，宽度至少 1000 px。
5. prototype-result.webp：颜色及公式结果截图，建议 2:1，宽度至少 1000 px。

后面三张尽量来自同一次识别。只提供一张高清完整截图也可以，后续再裁切局部。普通 PNG/JPEG 同样可用，修改 assets.ts 中的路径即可。截图不应暴露无关个人信息，不要重绘结果或添加未经系统输出的性能数字。
