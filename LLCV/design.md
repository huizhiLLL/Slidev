## 第二轮信息组织

保持白纸学术排版，以流程、约束和开放式表格提高第 2–6 页的有效信息密度。核心结论与关键技术词必须出现在可见页面，备注用于解释。正文 21–24 px，技术标签、图注和公式释义 17–20 px；通过短句和分组组织内容，不持续缩小字体。

主体时间为 7 分 30 秒，各页版式与预算见第 4 节。第 13 章限定研究粒度，第 14 章仍为叙事依据；数学符号来自已有状态约束，详细推导和 62,208 理想离散穷举记录保留备用 A，不挤占核心页。MCP/Agent 仅沿用第 4 章已有应用背景，不增加本期算法研究或模型比较承诺。

主体内容区域从 y≈150 到 y≈595。第三页技术链约 215 px、验证区约 150 px；第六页三条研究线与五行评价左右对齐。标题、校徽、页脚及共享过渡名称保持原有规范。新增文字后刷新 Noto 衬线字体子集；完成后检查八页（七页研究内容加致谢）、五页备用、450 秒讲述预算和生产资源，不使用浏览器自动化。

第 3 页求和约束使用 textstyle，将下标置于求和号侧边，避免 displaystyle 大型运算符撑高技术链。此修订依据用户提供的实际重叠截图，保留约束内容与正常正文字号。

按用户后续截图要求，移除第 3 页 OLL 举例与候选边界补充、第 4 页已有先例补充句、第 5 页工程基础 / 未量化 / 未训练补充、第 6 页底部比较原则。相关解释保留在讲稿；第 6 页研究线仍直接注明学习模型“后续探索 · 未训练”，不改变事实状态。

## 2. 视觉规范

视觉方向：白纸学术排版。黑字、大幅真实照片、克制的彩色标注。通过字形、留白与对齐建立层级，不使用卡片网格和装饰插画。

画布 1200 × 675，16:9。左右安全边距 64 px，顶部 44 px，底部 44 px。主体区约 y=150–595；底部保留统一页码。背景 #FFFFFF，正文 #202124，次级文字 #62676D，分隔线 #D9DDE1，图片占位底色 #F7F8F9。

强调色：蓝 #285EB5、绿 #27775E、橙 #B96024、红 #B84545，辅以少量黄色 #D0A42A。彩色只用于图中阶段编号、研究路线和文字级强调，不能单独承担状态信息。

现有基础用实线与明确文字标记，拟探索路线用虚线及“后续探索”文字标记。除关键条件和证据边界外，不在页面堆砌说明文字。

学校标识使用用户提供的 1768 × 461 透明 PNG，保留原始比例、颜色和透明通道。主体与备用页均由共用 DeckFooter 组件渲染校徽，固定于右上角 x=956、y=24，宽 180 px、高约 47 px，右侧距画布 64 px。页眉右侧为校徽保留约 210 × 60 px 的区域；标题位于其下方，封面照片下移至 y=100。第五页状态与流程说明位于截图右侧正文区，不占据校徽区域。

## 3. 字体

标题优先采用本机仓耳今楷，跨设备使用随项目提供的 Noto Serif SC 衬线子集。正文优先采用随项目提供的 MiSans，系统回退依次为 PingFang SC、SF Pro Text。避免使用微软雅黑、默认黑体作为设计字体。

封面标题约 44–46 px，页标题 39 px，正文 21–24 px，图注 17–18 px，页脚 13–14 px。正文行高约 1.55。技术标签与参考文献允许 18–20 px。不会为了塞字持续缩小字号。

字体本地提供，不从 Google Fonts 或远端 CDN 临场加载。仓耳今楷只通过 local() 调用，不复制本机商业字体文件。Noto 子集附 OFL，MiSans 注明来源与嵌入使用。

## 7. 组件与技术约定

采用 Slidev 默认主题作为运行基础，所有展示规范由项目内 styles/index.css 覆盖。单一 CSS 策略为语义类与 CSS 变量，不混用额外 UI 库或大套工具类。

AssetFrame 负责真实图片和缺图占位；ResearchFlow 与 ResearchRoadmap 用原生 Vue/HTML/CSS 编写可编辑技术图，不作为装饰。主体与备用页公式由 MathBlock 通过 KaTeX 渲染，避免 HTML 内嵌 Markdown 的解析歧义。DeckFooter 在每页统一提供右上角校徽及底部项目名、主体／备用页编号，校徽资源路径跟随构建 base。

不使用渐变、投影、玻璃效果、背景粒子、圆角卡片、动态数字、自动轮播和逐项点击显现。技术流程在一页内完整可读。照片、流程及标题承担视觉重心。

动效采用 Slidev 内置 View Transition：整页约 280 ms 柔和交叉淡入淡出，入场仅上移 6 px；校徽与页脚作为共享元素保持位置连续，普通页标题轻柔衔接，封面照片与第二页观测图以同一共享名称连接。共享元素使用约 340 ms 的缓出曲线，图片仍保留完整内容。不支持该 API 时，用同名 Vue 过渡类提供普通淡入淡出。

动效只发生在翻页，不增加讲述点击步骤；连续翻页沿用 Slidev 导航机制。概览、缩略图、打印由 Slidev 的非主视图隔离共享名称，打印样式额外取消动画。系统设置 prefers-reduced-motion: reduce 时关闭翻页、共享元素和入场动画。

## 8. 目录与 Git

根目录 Slidev/ 建立一个 Git 仓库，子项目不放 .git。理由是这里要成为幻灯片集合，统一历史、忽略规则和项目目录更适合日常维护；只有需要完全独立权限与发布历史时才拆仓库。

当前采用独立子项目，暂不引入 workspace、共享主题包或复杂 monorepo 工具。每个项目有自己的 package.json 和锁文件，可独立安装、运行和迁移；根 package.json 提供常用命令与集合构建入口，无额外前端框架依赖。多个项目出现稳定的公共规范后再抽取共享主题。

  .git/                    # 集合级版本历史
  .gitignore
  README.md                # 项目索引、Git 与目录约定
  package.json             # LLCV 的便捷命令
  魔方视觉识别_SITP前期调研与汇报提纲.md  # 原始研究资料，保留位置
  LLCV/
    design.md              # 本设计
    README.md              # 运行、素材替换、导出与演讲说明
    package.json

集合统一使用公开 GitHub 仓库 Slidev，集合导航页和 Cloudflare Pages 部署设计见根 design.md。忽略 node_modules、dist、导出产物和缓存，保留源文件、锁文件、设计与必要静态资产。
